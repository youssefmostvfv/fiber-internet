# 📖 دليل فهم وتطوير موقع fiber-5g-internet.com

أهلاً بك في الدليل التعريفي والتطويري لمشروع موقع **fiber-5g-internet.com**. تم إعداد هذا الملف لتسهيل فهم هيكلية المشروع وكيفية تشغيله وتعديله لأي مطور أو مستخدم يعمل عليه لاحقاً.

---

## 📌 1. فكرة وهدف المشروع
الموقع عبارة عن منصة لموزع معتمد (Authorized Reseller) لخدمات الاتصالات في المملكة العربية السعودية، وتحديداً في **مدينة الدمام والمنطقة الشرقية**.
يعمل الموقع كـ "وسيط ومندوب تسويق وتأسيس ميداني" لتقديم الخدمة للشركات الأربع الرئيسية:
- **STC** (إس تي سي)
- **Salam** (سلام)
- **Mobily** (موبايلي)
- **Zain** (زين)

### الخدمات المقدمة:
1. **تأسيس واشتراك الألياف البصرية (فايبر):** عروض الباقات والسرعات والتغطية.
2. **إنترنت 5G و4G المنزلي:** أجهزة الراوترات والباقات المنزلية.
3. **استقبال الطلبات عبر الواتساب المباشر:** جمع بيانات العميل ورقم البوكسية/الموقع الميداني.
4. **أداة قياس سرعة الإنترنت (Speed Test):** أداة تفاعلية تجعل الزائر يقيس سرعته الحالية وتوصيه بالترقية المناسبة.

## 🛠️ 3. كيفية التطوير وبناء التنسيقات (Tailwind CSS Workflow)

بما أن ملفات Tailwind مجمعة بالكامل داخل المجلد المخصص `assets/tailwind/`؛ يمكنك تشغيل التحديث التلقائي أو البناء بالخطوات التالية:

### أ) للتطوير والتحديث المباشر أثناء كتابة الكود (Watch Mode):
افتح التيرمينال في مجلد `assets/tailwind` وشغل الأمر:
```bash
cd assets/tailwind
npm run watch:css
```
*(هذا الأمر سيراقب أي تعديل في ملفات الـ HTML ويعيد بناء `assets/css/style.css` فوراً).*

### ب) للبناء النهائي والتصغير (Production Build):
```bash
cd assets/tailwind
npm run build:css
```

## 📞 5. منطق التحويل وطلب الخدمات (WhatsApp Logic)
جميع أزرار الطلب في الصفحة توجه الزائر لمحادثة الواتساب مباشرة مع تضمين قالب رسالة محدد يحتوي على:
- نوع الخدمة (فايبر / 5G).
- اسم الشركة المختارة.
- الحي في مدينة الدمام.
- رقم البوكسية / الموقع الجغرافي.
