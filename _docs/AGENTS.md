# fiber-5g-internet.com

## فكرة الموقع
موقع موزع معتمد (Authorized Reseller) لخدمات الاتصالات في السعودية، يعمل كـ "وسيط / مندوب مبيعات وتركيب ميداني".

## ما يقدمه الموقع:
* **تأسيس واشتراك الفايبر (الألياف البصرية):** لشركات الاتصالات الرئيسية (STC، سلام Salam، زين Zain، موبايلي Mobily).
* **إنترنت منزلي 5G و4G:** عروض الباقات المنزلية والراوترات للشركات نفسها.
* **استقبال الطلبات:** جمع بيانات العميل وموقع "البوكسية" للتواصل معه عبر واتساب وتنسيق التركيب مع المندوبين والفنيين.

## النطاق الجغرافي والخدمات:
* تقديم الباقات للإنترنت والاشتراكات والمعلومات.
* **المنطقة المستهدفة:** منطقة الدمام.

## 📌 قواعد القوالب والعناصر الثابتة (Global Layout Consistency):
- **النافبار الرئيسي (Navbar):** يجب تثبيت نفس الهيدر والنافبار بالشعار والروابط وأزرار التبديل في الصفحة الرئيسية وجميع الصفحات الفرعية (`companies`, `order`, `blog`, `speedtest`, `reviews`, `contact`).
- **الأزرار العائمة (Floating Action Stack):** تثبيت عمود الأيقونات العائمة (اتصال، واتساب، تقديم طلب 5s) في جميع صفحات الموقع.
- **مسارات الملفات النسبية:** مراعاة تعديل المسارات النسبية (مثلاً `../assets/` للصفحات الفرعية) حتى تعمل التنسيقات والأيقونات والأنيميشن بكفاءة 100%.

## أداة اختبار السرعة (Speed Test):
* خاصية قياس سرعة الموقع/الإنترنت التفاعلية لإفادة الزائر والتوصية بترقية الباقة مناسبة.

## البنية والمجلدات الأساسية:
- `_docs/`
- `assets/` (وسائط وصور وتنسيقات)
- `blog/` (المدونة)
- `companies/` (الشركات)
- `reviews/` (آراء العملاء)
- `contact/` (تواصل معنا)
- `order/` (تقديم طلب)
- `speedtest/` (اختبار السرعة)
